# TechMart - Shopping App

## Description
TechMart is a simple shopping website developed using HTML, CSS, JavaScript, Node.js, and Express.js. It allows users to browse products, manage their cart, create an account, log in, and view their profile through a user-friendly interface.

## Features
- Home Page
- User Login
- User Signup
- Product Listing
- Shopping Cart
- User Dashboard
- User Profile
- Responsive Design
- Express.js Server

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js

## Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install dependencies:
   ```
   npm install
   ```
4. Start the server:
   ```
   node server.js
   ```
5. Open your browser and visit:
   ```
   http://localhost:3000
   ```
